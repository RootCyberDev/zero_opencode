Place local PDF font files here.

Recommended files:

- `PdfSans-Regular.woff2`
- `PdfSans-Semibold.woff2`
- `PdfSerif-Regular.woff2`
- `PdfSerif-Semibold.woff2`

These names are already referenced by the PDF HTML starter.

If you prefer a different family, either:

1. replace these files with your chosen fonts using the same filenames, or
2. update the `@font-face` rules in:
   - `.opencode/skills/pdf/STARTER.html`
   - `skills/pdf/STARTER.html`
