Place local PDF font files here.

Recommended files:

- `PdfSans-Variable.ttf`
- `PdfSerif-Variable.ttf`
- `PdfIcons-Outlined.woff2`

These names are already referenced by the PDF HTML starter.

Recommended official sources:

1. Manrope variable font from Google Fonts repo:
   - `https://github.com/google/fonts/tree/main/ofl/manrope`
   - file: `Manrope[wght].ttf`
   - rename to: `PdfSans-Variable.ttf`

2. Source Serif 4 variable font from Google Fonts repo:
   - `https://github.com/google/fonts/tree/main/ofl/sourceserif4`
   - file: `SourceSerif4[opsz,wght].ttf`
   - rename to: `PdfSerif-Variable.ttf`

3. Material Symbols Outlined variable font from Google's official icons repo:
   - `https://github.com/google/material-design-icons/tree/master/variablefont`
   - file: `MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].woff2`
   - rename to: `PdfIcons-Outlined.woff2`

Raw file URLs you can download directly:

- `https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf`
- `https://raw.githubusercontent.com/google/fonts/main/ofl/sourceserif4/SourceSerif4%5Bopsz%2Cwght%5D.ttf`
- `https://raw.githubusercontent.com/google/material-design-icons/master/variablefont/MaterialSymbolsOutlined%5BFILL%2CGRAD%2Copsz%2Cwght%5D.woff2`

If you prefer a different family, update the `@font-face` rules in:
- `.opencode/skills/pdf/STARTER.html`
